## 🚀 Quick Start for Local Development

### Prerequisites
- Node.js 20+ LTS (`node -v`)
- npm (`npm -v`)

### Start All Servers with One Command (macOS)
```bash
./START_SERVERS.sh
```

### Manual Commands
```bash
# Backend (Port 5001)
cd backend
npm install
npm test
npm run dev

# Frontend (Port 3000)
cd frontend
npm install
npm run dev
```
